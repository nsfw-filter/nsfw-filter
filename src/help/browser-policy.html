Browser policy setup

Setting a password protects NSFW Filter's settings. It does not prevent the extension from being disabled or removed.

A browser policy is a setting controlled by the device administrator. Chrome's ExtensionInstallForcelist policy keeps NSFW Filter installed and prevents users from disabling or removing it through Chrome.

This may help when setting up NSFW Filter for a child. If you only want an extra step before changing settings, a password alone may be enough.

See Chrome's official setup guidance for configuration instructions.

The warning is hidden when the browser confirms force-install protection.
